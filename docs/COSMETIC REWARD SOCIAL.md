Lazplay — Cosmetic, Reward, and Social Identity System
Vision
The cosmetic system is designed to:

increase player engagement
create social identity
reward platform activity
encourage indie game discovery
support platform sustainability
motivate developers and players

The goal is NOT pay-to-win.
The goal is:

recognition
personalization
progression
visibility
community identity


Core Philosophy
Lazplay cosmetics should feel:

earned
collectible
visible
social
platform-wide

The system should encourage:

supporting developers
community interaction
