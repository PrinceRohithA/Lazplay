# Catalyst Agent Notes

This file records the current migration posture for future agents.

## Non-Negotiables

- Work only inside `lazplay-catalyst/`.
- Do not modify launcher logic.
- Do not replace Cloudflare R2.
- Do not add ZIP extraction, game asset rebundling, or large file streaming to Catalyst.
- Catalyst handles APIs, auth orchestration, metadata, cache, and business logic.
- R2 handles chunks, manifests, web builds, binaries, screenshots, and CDN assets.

## Current Scaffold

- AppSail backend: `backend/src/catalyst/server.js`
- Web client deploy output: `client/dist`
- React source copy: `frontend`
- Cache plan: `iac/cache-segments.json`
- Data Store plan: `iac/datastore.schema.json`
- API Gateway rules: `catalyst-user-rules.json`
- Deployment docs: `docs/DEPLOYMENT.md`

## Official Docs Caveat

The current Catalyst docs state that `project-template.json` is generated by Catalyst export and is required for IaC import ZIPs. They also state that manually generating this file is not currently supported. The file in this workspace is therefore a local draft marker, not a replacement for a real `catalyst iac:export` output.

After the Catalyst console resources are created, run:

```powershell
catalyst iac:export
```

Then replace the local draft `project-template.json` with the exported one if you plan to use `catalyst iac:pack` or `catalyst iac:import`.
